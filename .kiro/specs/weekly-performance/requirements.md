# Weekly performance requirements

Source: weekly performance references in `docs/design/`.

- Home Weekly Stats SHALL push `WeeklyPerformanceContainerView`.
- The default mode SHALL be running until profile sports exist.
- Running SHALL show the reference fixture: 18.4 mi, 2,450 cal, 8:12 /mi, 158 bpm, 5/7 consistency, and the three highlights.
- Powerlifting SHALL show the reference fixture: 16 lifts, 12,450 lbs, 4h 32m, 194 lbs, four lift cards, recent PRs, and last workout.
- Debug builds SHALL expose a Running | Powerlifting preview control.
