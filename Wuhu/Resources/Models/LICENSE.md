# Body model license

HealthTracker ships a **procedural** RealityKit body (simple boxes named to match `BodyPart` raw values). That geometry is original to this project.

## Optional `body.usdz`

Place a gender-neutral, low-poly human figure at:

```
HealthTracker/Resources/Models/body.usdz
```

Requirements:

- Child entity names must match `BodyPart` raw values exactly (`leftQuad`, `rightKnee`, …).
- Prefer CC0 or another license that allows redistribution.
- Keep the file under about 5 MB and under 50k triangles.
- Record the source URL and license text in this file when you add an asset.

Do **not** use ripped or unlicensed game models.
